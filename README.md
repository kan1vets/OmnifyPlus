## ✨ Основные возможности

* **☁️ Два облака в одном окне (Google Диск + Яндекс Диск):** полноценное управление файлами и папками обоих хранилищ с наглядной цветовой индикацией (синий акцент для Google, жёлтый для Яндекса) и точным отображением занятого места.
* **🎬 Скачивание видео с YouTube в 4K и FullHD:** встроенный загрузчик видео с выбором качества (`4K 2160p`, `1080p`, `720p`, `480p`), автоматической докачкой и склейкой видео- и аудиопотоков в `.mp4` через `yt-dlp` и `FFmpeg`.
* **🔄 Межоблачное копирование (Cloud to Cloud):** прямой перенос папок и файлов по ссылкам во всех направлениях (`Google ⇄ Яндекс`, `Google → Google`, `Яндекс → Яндекс`) без сохранения на ПК, с отслеживанием прогресса как во вкладке переноса, так и в общем списке «Загрузки».
* **📥 Скачивание папок без ZIP-архивов:** полная рекурсивная выгрузка вложенной структуры папок и файлов по публичным ссылкам или напрямую со своего Google Диска и Яндекс Диска.
* **⏯️ Докачка и сохранение очереди:** пауза и безопасное возобновление скачивания, выгрузки и межоблачного переноса с места остановки даже после перезапуска программы.
* **🖱️ Drag & Drop внутри и между окнами:** перетаскивание локальных файлов и папок из проводника Windows прямо в облако, а также перемещение объектов между папками внутри самого Google Диска и Яндекс Диска с визуальной подсветкой.
* **🗑 Единая умная корзина:** быстрое переключение между корзинами Google Диска и Яндекс Диска, просмотр вложенных папок, выборочное восстановление и асинхронная полная очистка.
* **⚡ Мгновенный отклик интерфейса:** асинхронная подгрузка профилей и списков файлов в фоновых потоках с кэшированием в памяти обеспечивает мгновенное переключение между вкладками без зависаний.
* **📄 Умный экспорт Google Документов:** автоматическое преобразование Google Docs / Sheets / Slides в форматы `.docx`, `.xlsx`, `.pptx` при скачивании и переносе между облаками.
* **📊 Калькулятор размера папок и быстрый шеринг:** рекурсивный подсчёт реального веса любой папки с кэшированием результата и создание публичных ссылок с копированием в буфер обмена в один клик.
* **🚦 Глобальный шейпер трафика:** потокобезопасное ограничение суммарной скорости загрузки (в **Мбит/с**) на лету для всех активных задач.
* **🚀 Встроенное автообновление (OTA):** проверка новых релизов на GitHub с отображением списка изменений, докачкой обновления при обрывах связи и автоматическим перезапуском.

## 🗺 Планы на будущие обновления (Roadmap)

**Omnify+** активно развивается как единый комбайн для всех типов загрузок и хранилищ. В ближайших обновлениях появятся:

- [ ] **Загрузка видео и медиа из соцсетей:** поддержка **TikTok**, **Instagram**, **X (Twitter)** и других платформ.
- [ ] **Встроенный Торрент-клиент:** скачивание `.torrent` файлов и `magnet`-ссылок напрямую через интерфейс программы.
- [ ] **Новые облачные хранилища:** расширение списка поддерживаемых облачных сервисов для проводника и режима Cloud-to-Cloud.

## 🛠 Стек технологий

* **GUI:** PyQt6 (Custom Dark Theme, Frameless Dialogs, RubberBand Selection, Internal & External Drag & Drop)
* **Cloud API:** Google Drive API v3 (`google-api-python-client`, `google-auth-oauthlib`), Yandex Disk REST API v1 (`cloud-api.yandex.net`)
* **Media Engine:** `yt-dlp` + автоматическая инициализация `FFmpeg` и `Deno JS Runtime` для потоков 4K/1080p
* **Network:** `requests` (Connection Pooling, Chunked Streaming, HTTP Range headers, Global Bandwidth Throttling, Local OAuth Callback Server)
